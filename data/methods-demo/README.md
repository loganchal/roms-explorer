# Online stratification budget construction

One offshore column near 170 E, 40 S; 1 July 2008–30 June 2009.
365 consecutive daily records; the initial profiles and accumulated
contributions use 1 July as their reference.

Generated by tools/export_budget_demo.py at revision 43b1b022b34ef31c216d538cf23268c47d4880c5,
Aoraki Slurm job 6423948. The JSON records the actual coordinate,
immutable hindcast release filenames and sizes, all online process terms,
daily start/end PEA, and daily-mean T/S profiles. This is a methods example;
no climate classifications, phase composites or thesis interpretations appear.

PEA interval: surface to 200 m. Archived rates: W m^-3. Displayed daily
rates: J m^-3 day^-1. Time integration uses 86400 seconds per record.
The total interior mixing term is included once; mixing component diagnostics
are not double counted. Horizontal and vertical advection are grouped in the
interface. Dilution, moving geometry, tracer-ledger residuals and nonlinear
EOS terms are displayed together as corrections.

Validation:
- Maximum process-sum discrepancy: 1.3325059462543408e-09 W m^-3.
- Maximum daily tendency/state-change discrepancy: 2.7475878596305847e-05 J m^-3.
- Maximum consecutive end/start PEA gap: 0.0 J m^-3.
- Final accumulated reconstruction error: 0.00046563833647184083 J m^-3.
The discrepancies are consistent with archived field precision.

Profiles are context, not offline-reconstructed process tendencies. The browser
calculates surface-referenced potential density from daily-mean T/S using ROMS's
Jackett–McDougall den1 polynomial, displaying sigma-theta = rho-theta - 1000
kg m^-3. It is distinct from in-situ density and PEA. The calculation was checked
against the independent Atlas ROMS EOS port for the initial seasonal dataset
and its reference/clamping cases (6519 states, zero numerical discrepancy).

The interface is one linked workspace and one date control. A locator is built
by tools/build_budget_locator.py from the explorer's existing native land mask.
North is up; longitude scales by cos(41 degrees). The point uses the exported
column coordinate; no external map service is used.

The Monet band uses the existing Rough weather at Etretat image at
/assets/monet/ngv.webp; the academic site's assets/monet/sources.json retains
its source metadata. Charts have no image overlay or tint.

The demo is linked from Run forward. Its return link restores that stage
without repeating the entrance. The old result-based drafts remain outside
this repository and the local preview server.
